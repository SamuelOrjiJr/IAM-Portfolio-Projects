## How each project is documented

- **Scenario:** the business problem the configuration solves
- **Build:** every step with a labeled screenshot
- **What broke:** real issues hit mid-build and how I resolved them
- **Proof:** evidence from logs, simulations, or audit data that it works as designed
- **Key concepts:** the identity principles the lab reinforced

All public IP addresses and sensitive values are blurred in screenshots.
